About Xizi Pumps

关于西子泵业

我们面向污水处理厂、市政管网、建筑排污、河湖调水及工业废水等场景，提供从单机设备到成套泵站的一体化解决方案。 产品结构涵盖铸铁、不锈钢、双相钢等多种材质，满足腐蚀、磨蚀与高温介质的差异化工况。

系统思维，而非单机交付 从水力选型、土建接口、电气自控到运维备件，以总包视角降低客户多供应商协调成本。
材质与结构可工程化配置 过流部件可选耐磨涂层、双相钢或整体不锈钢，密封与轴承系统按介质含固率与温度分级选型。
对标国际品牌的项目语言 技术文档、 FAT/SAT 见证与运行手册按 EPC 与业主方审计习惯输出，便于纳入大型基建与技改框架。
可持续运行与节能 高效水力模型、变频运行策略与泵组优化调度，助力客户降低全生命周期能耗与碳足迹。

潜水排污泵（多材质）

Submersible sewage pumps · WQ / WQ-H / stainless & duplex options

适用于输送城市生活污水、工业废水及含固体颗粒与纤维的介质。叶轮型式包括单通道、双通道、旋流式与切割式， 可通过水力模型匹配防缠绕与通过能力。过流材质可选灰铸铁、球墨铸铁、304/316L 不锈钢及双相钢， 密封系统按介质温度与含固率配置单端面机械密封、双端面机械密封或集装式密封，并可选泄漏监测与轴承温升保护。

型号示例（西子口径）：150WQA150-21-15-4P-Z — 依次为排出口径（mm）、系列代号（如 WQA）、额定流量（m³/h）、额定扬程（m）、电机功率（kW）、电机极数（如 4P）、安装方式代号（Z 为自动耦合式等）。 可在下方 「型号报价」 中实时解析并生成询价摘要。

典型配套：不锈钢导杆自动耦合装置、出水弯管、双导轨起吊系统；控制侧支持直接启动、星三角、软启动与变频器。

口径 / OutletDN50–DN600（可扩展至更大口径项目定制）
流量 / Flow约 5–5500 m³/h（按系列与电机配置）
扬程 / Head约 5–100 m
介质温度常规 ≤40 °C；高温型可达 ≤80 °C（选型确认）
电机IE3 效率等级（可按项目指定 IE4 / 防爆）

污水提升器

Sewage lifting stations · PE / GRP tank · duplex pump logic

针对无法重力排入市政管网的场景，提供单泵或双泵互备提升单元。箱体可选聚乙烯滚塑或玻璃钢材质， 内置液位浮球/投入式液位计、止回阀、闸阀及通气管路；双泵系统具备轮换运行、故障切换与高液位报警。 可集成切割泵或通道泵以应对卫生巾、纤维类缠绕物。

有效容积约 60–3000 L（按停留时间与峰值流量计算）
安装方式地面式 / 地埋式 / 夹层式
控制PLC 或专用控制器；可选 GSM 短信 / 4G 远程报警
标准与认证按项目目标市场协助整理 CE / 国内质检等符合性文件

潜水搅拌机与推流器

Submersible mixers & flow promoters

用于生物处理池内泥水混合、固体悬浮与推流，防止沉积。推流器采用低速大叶轮设计，配合安装导杆与转向角可调底座， 改善流场分布并降低能耗。电机 F 级绝缘，标配过热与泄漏保护；不锈钢或环氧涂层叶轮适应腐蚀性环境。

搅拌机功率约 0.37–22 kW
推流器功率约 1.5–250 kW（低速系列）
安装导杆升降、池壁支座、转向角可调支架
选型方法按池型 CFD / 经验速度梯度 G 值与体积功率密度校核

轴流泵与混流泵

Axial & mixed-flow pumps · flood control & circulation

面向雨水排涝、河道调水、冷却循环等大流量工况。立式井筒安装与雪橇式移动泵站均可提供； 叶片角度可调（动叶 / 静叶调节）以拓宽高效区。可与行星齿轮箱或低速电机直联，配合液压全调节装置实现多工况优化运行。

口径DN350–DN1600+（工程定制）
流量可达数万 m³/h 级（按装置汽蚀余量与土建限制）
结构形式立式轴流、导叶式混流、贯流式
驱动电机、柴油机应急驱动可选

一体式智能泵站及泵房

Integrated intelligent pumping station & packaged pump house

采用工厂预制筒体（玻璃钢 / 不锈钢 / 混凝土外挂板），内部集成水泵、阀门、止回、格栅除污、输送压榨、 通风除臭、消防与安全疏散通道。自控层集成 PLC、UPS、防雷与工业以太网交换机，可选云平台实现多泵站集群监控、 能耗对标与预测性维护。适用于道路立交排水、老旧小区雨污分流改造、农村污水连片整治及工业厂区雨水回收。

交付边界可包含：工艺 PID、BIM 配合、设备 FAT、现场 SAT、运维培训与两年备件建议清单。

筒体直径常见 φ1200–φ4500 mm（项目定制）
泵台数1–6 台（变频并联或大小泵搭配）
格栅回转式、阶梯式、粉碎性格栅可选
云平台Web/APP 告警、报表、权限分级与 API 对接
